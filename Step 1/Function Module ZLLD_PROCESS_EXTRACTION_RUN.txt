FUNCTION ZLLD_PROCESS_EXTRACTION_RUN.
*"----------------------------------------------------------------------
*"*"Local Interface:
*"  IMPORTING
*"     VALUE(IV_RUN_ID) TYPE  SYSUUID_X16
*"  EXPORTING
*"     VALUE(EV_STATUS) TYPE  CHAR12
*"     VALUE(EV_MESSAGE) TYPE  STRING
*"----------------------------------------------------------------------

*&---------------------------------------------------------------------*
*& ZLLD_PROCESS_EXTRACTION_RUN
*&---------------------------------------------------------------------*
*  STUB for step1_db_mode_brief.md. Built to validate the actual
*  interface contract (what ZLLD_PACKAGE_EXTRACTOR's DB-mode path
*  passes, what it gets back) against a real call - not a paper design.
*
*  Real logic is intentionally OUT OF SCOPE here, per the brief: reading
*  ZLLD_STG_OBJECT/_DEPENDENCY/_DDIC for this RUN_ID, deriving EDGE_KIND
*  from each dependency's raw DEPENDENCY_TYPE, chunking/tokenizing
*  source, and loading all of it into final query-ready graph tables.
*  That is a separate, later brief, once this staging contract is
*  confirmed working end to end.
*
*  This stub does exactly three things:
*    1. Confirms the ZLLD_STG_RUN row for IV_RUN_ID actually exists
*       (the one thing a real caller needs to trust before treating the
*       hand-off as successful).
*    2. Sets that row's STATUS to 'STUB_OK'.
*    3. Returns EV_STATUS = 'STUB_OK' and a message saying so plainly -
*       never claims real processing happened.
*
*  VERIFY: this has not been created/tested in the system - the
*  IMPORTING/EXPORTING interface above is written to match the brief's
*  call site in ZLLD_PACKAGE_EXTRACTOR::CALL_PROCESS_EXTRACTION_RUN
*  exactly (parameter names, types, and passing mode all line up), but
*  create it via SE37 and confirm the generated interface matches this
*  text before assuming it does.
*&---------------------------------------------------------------------*

  DATA ls_stg_run TYPE zlld_stg_run.

  CLEAR: ev_status, ev_message.

  SELECT SINGLE * FROM zlld_stg_run INTO ls_stg_run WHERE run_id = iv_run_id.

  IF sy-subrc <> 0.
    ev_status  = 'FAILED'.
    ev_message = |No ZLLD_STG_RUN row found for RUN_ID { iv_run_id }. Nothing to process.|.
    RETURN.
  ENDIF.

  ls_stg_run-status = 'STUB_OK'.
  MODIFY zlld_stg_run FROM ls_stg_run.

  ev_status  = 'STUB_OK'.
  ev_message = |Staged successfully; native processing not yet implemented.|.

ENDFUNCTION.
