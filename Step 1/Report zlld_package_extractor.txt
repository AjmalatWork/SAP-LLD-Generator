REPORT zlld_package_extractor.

*&---------------------------------------------------------------------*
*& ZLLD_PACKAGE_EXTRACTOR
*&---------------------------------------------------------------------*
*  Step 1 of the LLD tool: package-scoped extraction with transport
*  sync. First run against a package = full extraction of every
*  PROG/CLAS/FUNC (incl. FUGR members) it contains. Every run after
*  that = incremental: only objects touched by released transports
*  since the last sync, plus deletion detection against the package's
*  live TADIR contents. Output is written in the LLD block format that
*  lld_step2.parser (the Python side of this tool) already understands
*  - see the brief this was built from for the exact format.
*
*  This is a NEW, separate report. It reuses ZCR_GET_DEPENDENCY_OBJ_NEW,
*  ZCR_GET_OBJECT_SIGNATURE and Z_GET_DDIC_INFO exactly as they exist
*  (no changes to any of the three), and reuses several forms from
*  ZCR_AURA_CODE_EXTRACTOR verbatim or near-verbatim (marked "REUSED"
*  below). Nothing about ZCR_AURA_CODE_EXTRACTOR's own behavior changes.
*
*  REQUIRES (already created - see DDIC_TABLES_TO_CREATE_LLD.txt):
*    - Table ZDCCRT_SYNC_LOG
*    - Table ZDCCRT_SYNC_OBJ
*
*  REQUIRES for DB output mode (step1_db_mode_brief.md +
*  step2_native_processing_brief.md - created, but see
*  DDIC_TABLES_TO_CREATE_LLD.txt's "as-built" notes: several of these
*  were renamed/retyped from the original ZLLD_* proposal to match this
*  system's own naming convention and its rejection of STRING as a table
*  key component - the ABAP code below uses the AS-BUILT names):
*    - Table ZDCCRT_STG_RUN, ZDCCRT_STG_OBJ, ZDCCRT_STG_DEP, ZDCCRT_STG_DDIC
*    - Table ZDCCRT_OBJECTS, ZDCCRT_OBJ_CALLS, ZDCCRT_OBJ_DDREF,
*      ZDCCRT_DDIC_OBJ, ZDCCRT_CHUNKS, ZDCCRT_CHUNK_TOK, ZDCCRT_EKIND_MAP,
*      ZDCCRT_CONFIG
*    - The native chunk/token/graph load itself is a plain INCLUDE, not
*      a function module (no SE37/function group setup needed) - see
*      "INCLUDE zlld_extract_to_db_f01." below and
*      Step 1/Include ZLLD_EXTRACT_TO_DB_F01.txt.
*    - ZDCCRT_STG_DEP's key originally lacked DEPENDENCY_SEQ (would have
*      failed every dependency after the first per object on a duplicate
*      key) - CONFIRMED FIXED, DEPENDENCY_SEQ is now part of the key
*      (MANDT, RUN_ID, OBJ_NAME, DEPENDENCY_SEQ).
*    - ZDCCRT_STG_DDIC's DETAIL_JSON field (TYPE Z_STRING, non-key) -
*      CONFIRMED added.
*  File mode (the default) needs none of the above and is unchanged.
*
*  SEVERAL FM CALLS BELOW ARE FLAGGED "VERIFY" - their exact parameter
*  names/types are written from best recollection, not from a live
*  system, since this was built without SAP access. Check each one in
*  SE37 before activating. See LLD_EXTRACTOR_DESIGN_NOTES.md for the
*  full list and for the acceptance-criteria test plan.
*&---------------------------------------------------------------------*

* Native chunk/token/graph load (step2_native_processing_brief.md) -
* only exercised by the DB-mode path (CALL_EXTRACT_TO_DB below PERFORMs
* EXTRACT_TO_DB, defined in this include). Create this include as a
* normal ABAP program (SE38, program type "Include") from
* Step 1/Include ZLLD_EXTRACT_TO_DB_F01.txt before activating DB mode -
* file mode does not need it at all.

*& ALV event handler
*&---------------------------------------------------------------------*
*       Trimmed down from ZCR_AURA_CODE_EXTRACTOR's version: no F4 /
*       DATA_CHANGED handling at all, since this report drops the
*       "Compare Against Version" column and everything tied to it
*       entirely (this report has no diff/version-comparison concept -
*       it only ever extracts current active source). ON_TOOLBAR is
*       reused unchanged in behavior.
*&---------------------------------------------------------------------*
CLASS lcl_alv_event_handler DEFINITION.
  PUBLIC SECTION.
    METHODS on_toolbar FOR EVENT toolbar OF cl_gui_alv_grid
      IMPORTING e_object.
ENDCLASS.

" GO_ALV_EVENTS must be declared after the class it's typed as - same
" reason ZCR_AURA_CODE_EXTRACTOR declares its own equivalent separately
" from its main Global Data block.
DATA go_alv_events TYPE REF TO lcl_alv_event_handler.

CLASS lcl_alv_event_handler IMPLEMENTATION.
  METHOD on_toolbar.
    " Keep-list approach: delete every standard toolbar button except
    " Sort Ascending/Descending and Find. REUSED behavior from
    " ZCR_AURA_CODE_EXTRACTOR's own ON_TOOLBAR.
    DATA ls_toolbar TYPE stb_button.

    LOOP AT e_object->mt_toolbar INTO ls_toolbar.
      CASE ls_toolbar-function.
        WHEN cl_gui_alv_grid=>mc_fc_sort_asc
          OR cl_gui_alv_grid=>mc_fc_sort_dsc
          OR cl_gui_alv_grid=>mc_fc_find
          OR cl_gui_alv_grid=>mc_fc_find_more.
          " keep
        WHEN OTHERS.
          DELETE e_object->mt_toolbar.
      ENDCASE.
    ENDLOOP.
  ENDMETHOD.
ENDCLASS.

*&---------------------------------------------------------------------*
*& Selection Screen
*&---------------------------------------------------------------------*
* text-001: maintain via SE38 Text Elements, e.g. "Output Mode"
* Database is now the default (P_MDB = 'X') - File mode is opt-in.
* Nothing in MAIN branches on output mode until after CALL SCREEN 9000
* returns (see MAIN below) - the file path still executes exactly as
* before, with no new logic in between, when File mode is chosen.
*
* USER-COMMAND on P_MDB is required for P_FILE's hide/show to react
* live to a click - without it, radio buttons on a classic selection
* screen do NOT trigger a server round-trip (and so don't re-run AT
* SELECTION-SCREEN OUTPUT) until some other action forces one (Enter,
* F4 on another field, Execute) - which looks exactly like "the field
* never reappears," when really the PBO logic just hasn't run again
* yet. USER-COMMAND forces that round-trip immediately on any click
* within the group, on either button.
SELECTION-SCREEN BEGIN OF BLOCK b1 WITH FRAME TITLE text-001.
PARAMETERS: p_mdb   RADIOBUTTON GROUP outm DEFAULT 'X' USER-COMMAND ucomm,
            p_mfile RADIOBUTTON GROUP outm.
SELECTION-SCREEN END OF BLOCK b1.

* text-002: maintain via SE38 Text Elements, e.g. "Package & Output"
SELECTION-SCREEN BEGIN OF BLOCK b2 WITH FRAME TITLE text-002.
PARAMETERS: p_pack TYPE devclass OBLIGATORY,
            p_file TYPE string  DEFAULT 'C:\temp\' MODIF ID fil.
SELECTION-SCREEN END OF BLOCK b2.

AT SELECTION-SCREEN ON VALUE-REQUEST FOR p_file.
  PERFORM f4_output_folder CHANGING p_file.

*&---------------------------------------------------------------------*
*&      P_FILE (the output folder) is only meaningful in File mode -
*&      hidden entirely (not just disabled) when Database mode is
*&      selected.
*&
*&      NOT marked OBLIGATORY, deliberately - CONFIRMED against the
*&      real system that this matters, not just a theoretical concern:
*&      OBLIGATORY's mandatory-field check runs during PAI validation,
*&      which happens BEFORE this PBO logic gets a chance to hide the
*&      field again - with OBLIGATORY still set, that validation step
*&      interfered with the hide/show round-trip (triggered by
*&      P_MDB's USER-COMMAND) badly enough that the field could get
*&      stuck. DEFAULT 'C:\temp\' still keeps it populated in normal
*&      use without needing the hard mandatory check.
*&
*&      Toggles on SCREEN-GROUP1 ('FIL', via the PARAMETERS ... MODIF ID
*&      FIL above), not SCREEN-NAME = 'P_FILE' - a PARAMETERS field's
*&      input box and its text label are separate screen elements with
*&      their own SCREEN-NAME entries in the LOOP AT SCREEN table;
*&      toggling only the input box by name leaves the label visible
*&      (and, on some releases, the F4 icon too), which is the "hide/
*&      show isn't working correctly" symptom. MODIF ID tags every
*&      element on that line with the same SCREEN-GROUP1, so one check
*&      hides the whole row together.
*&---------------------------------------------------------------------*
AT SELECTION-SCREEN OUTPUT.
  LOOP AT SCREEN.
    IF screen-group1 = 'FIL'.
      screen-active = COND #( WHEN p_mfile = abap_true THEN 1 ELSE 0 ).
      screen-input  = screen-active.
      MODIFY SCREEN.
    ENDIF.
  ENDLOOP.

*&---------------------------------------------------------------------*
*& Main
*&---------------------------------------------------------------------*
START-OF-SELECTION.
  PERFORM main.

*&---------------------------------------------------------------------*
*&      Form  MAIN
*&---------------------------------------------------------------------*
*       Orchestrates the whole run: determine FULL vs INCR, run
*       deletion detection (always, regardless of run type), build the
*       candidate object list, show the ALV review screen, and - once
*       confirmed - write the LLD file and update sync state.
*
*       Output-mode branching (step1_db_mode_brief.md) happens ONLY
*       after CALL SCREEN 9000 returns, at the exact point file mode
*       already wrote its output - everything above that point (object
*       enumeration, sync, deletion detection, the ALV review) is
*       identical regardless of mode, and the FILE branch below calls
*       exactly the same three forms, in the same order, that this form
*       called unconditionally before this brief - a regression there
*       would mean genuinely new code executing on the file path, which
*       the brief treats as a hard requirement not to do.
*&---------------------------------------------------------------------*
FORM main.
  gv_output_mode = COND #( WHEN p_mdb = abap_true THEN 'DB' ELSE 'FILE' ).

  PERFORM validate_package.
  CHECK gv_error = abap_false.

  PERFORM read_sync_log USING p_pack CHANGING gs_sync_log gv_sync_found.
  gv_run_type = COND #( WHEN gv_sync_found = abap_true THEN 'INCR' ELSE 'FULL' ).

  " Deletion detection runs on every run - on a first (FULL) run there is
  " simply nothing stored yet to compare against, so it naturally yields
  " zero removed objects rather than needing a special case here.
  PERFORM build_package_inventory USING p_pack CHANGING gt_current_inventory.
  PERFORM detect_removed_objects USING p_pack gt_current_inventory
                                  CHANGING gt_removed_objects.

  CLEAR: gt_e071, gr_class_name, gt_hits, gt_lld_multi_obj, gv_extracted_count.

  IF gv_run_type = 'FULL'.
    PERFORM build_object_list_from_package USING p_pack.
    PERFORM convert_e071_to_lld_hits CHANGING gt_hits.
  ELSE.
    PERFORM gather_qualifying_transports USING p_pack gs_sync_log-last_trkorr_hwm
                                          CHANGING gt_qualifying_trkorr gv_new_hwm.

    LOOP AT gt_qualifying_trkorr INTO DATA(lv_qual_trkorr).
      PERFORM collect_tr_hits USING lv_qual_trkorr CHANGING gt_hits.
    ENDLOOP.

    IF gt_hits IS NOT INITIAL.
      PERFORM expand_class_methods CHANGING gt_hits.
    ENDIF.
  ENDIF.

  PERFORM build_unique_lld_objects USING gt_hits.
  PERFORM determine_lld_output_path USING p_pack gv_run_type.

  CLEAR gv_multi_cancelled.
  CALL SCREEN 9000.

  CHECK gv_multi_cancelled = abap_false.

  CASE gv_output_mode.
    WHEN 'DB'.
      PERFORM generate_run_id CHANGING gv_run_id.
      PERFORM build_and_stage_lld_db.
      PERFORM finalize_sync_state USING p_pack gv_run_type gv_new_hwm.
      PERFORM call_extract_to_db USING gv_run_id.
      PERFORM display_db_mode_result.

    WHEN OTHERS.  " 'FILE' - the default, byte-for-byte unchanged from
                  " before this brief.
      PERFORM build_and_write_lld_file.
      PERFORM finalize_sync_state USING p_pack gv_run_type gv_new_hwm.
      PERFORM download_output_file.
  ENDCASE.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  VALIDATE_PACKAGE
*&---------------------------------------------------------------------*
FORM validate_package.
  CLEAR gv_error.

  SELECT SINGLE devclass FROM tdevc INTO @DATA(lv_dummy) WHERE devclass = @p_pack.
  IF sy-subrc <> 0.
    MESSAGE |Package { p_pack } does not exist.| TYPE 'S' DISPLAY LIKE 'E'.
    gv_error = abap_true.
  ENDIF.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  F4_OUTPUT_FOLDER   (REUSED unchanged from ZCR_AURA_CODE_EXTRACTOR)
*&---------------------------------------------------------------------*
FORM f4_output_folder CHANGING cv_file TYPE string.
  DATA lv_selected_folder TYPE string.

  cl_gui_frontend_services=>directory_browse(
    EXPORTING
      window_title          = 'Select Output Folder'
      initial_folder        = 'C:\'
    CHANGING
      selected_folder       = lv_selected_folder
    EXCEPTIONS
      cntl_error            = 1
      error_no_gui          = 2
      not_supported_by_gui  = 3
      OTHERS                = 4 ).

  IF sy-subrc = 0 AND lv_selected_folder IS NOT INITIAL.
    cv_file = lv_selected_folder.
  ENDIF.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  DETERMINE_LLD_OUTPUT_PATH
*&---------------------------------------------------------------------*
FORM determine_lld_output_path USING iv_package  TYPE devclass
                                      iv_run_type TYPE char4.
  gv_filename = |LLD_EXTRACT_{ iv_package }_{ iv_run_type }.TXT|.
  PERFORM build_full_path.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  BUILD_FULL_PATH   (REUSED unchanged from ZCR_AURA_CODE_EXTRACTOR)
*&---------------------------------------------------------------------*
FORM build_full_path.
  gv_full_path = p_file.
  IF substring( val = gv_full_path off = strlen( gv_full_path ) - 1 ) <> '\'.
    gv_full_path = gv_full_path && '\'.
  ENDIF.
  gv_full_path = gv_full_path && gv_filename.
ENDFORM.

*&=======================================================================*
*& Package inventory (single source of truth for: full-run object list,
*& deletion detection's "today's list", and the qualifying-transport
*& package-membership filter)
*&=======================================================================*

*&---------------------------------------------------------------------*
*&      Form  BUILD_PACKAGE_INVENTORY
*&---------------------------------------------------------------------*
*       Every top-level PROG/CLAS/FUNC currently in IV_PACKAGE, with
*       FUGR expanded to its individual member FUNCs (same technique
*       ZCR_GET_DEPENDENCY_OBJ_NEW's WHEN 'FUGR' branch already uses:
*       TFDIR filtered to the function group's "SAPL<name>" pool,
*       Z*/Y* only). This is the CURRENT live inventory, independent of
*       what actually gets extracted this run.
*&---------------------------------------------------------------------*
FORM build_package_inventory USING iv_package TYPE devclass
                              CHANGING ct_inventory TYPE tt_lld_obj.
  " Explicit flat-table declarations, not inline SELECT ... INTO TABLE
  " @DATA(...) - a single-column inline SELECT always creates a table of
  " a one-component STRUCTURE in ABAP, never a flat table of that scalar
  " type, even though it looks like it should. Looping such a result
  " into a plain variable and using it directly (e.g. in a string
  " template) fails with "cannot be converted to a character-type
  " value" - this is exactly that gotcha, fixed by declaring the target
  " table's line type explicitly instead of letting it be inferred.
  DATA: lt_prog       TYPE STANDARD TABLE OF tadir-obj_name,
        lt_clas       TYPE STANDARD TABLE OF tadir-obj_name,
        lt_func       TYPE STANDARD TABLE OF tadir-obj_name,
        lt_fugr       TYPE STANDARD TABLE OF tadir-obj_name,
        lt_fugr_funcs TYPE STANDARD TABLE OF tfdir-funcname,
        lv_area       TYPE progname.

  CLEAR ct_inventory.

  SELECT obj_name FROM tadir INTO TABLE @lt_prog
    WHERE pgmid = 'R3TR' AND object = 'PROG' AND devclass = @iv_package.
  LOOP AT lt_prog INTO DATA(lv_prog_name).
    APPEND VALUE #( obj_type = 'PROG' obj_name = lv_prog_name ) TO ct_inventory.
  ENDLOOP.

  SELECT obj_name FROM tadir INTO TABLE @lt_clas
    WHERE pgmid = 'R3TR' AND object = 'CLAS' AND devclass = @iv_package.
  LOOP AT lt_clas INTO DATA(lv_clas_name).
    APPEND VALUE #( obj_type = 'CLAS' obj_name = lv_clas_name ) TO ct_inventory.
  ENDLOOP.

  SELECT obj_name FROM tadir INTO TABLE @lt_func
    WHERE pgmid = 'R3TR' AND object = 'FUNC' AND devclass = @iv_package.
  LOOP AT lt_func INTO DATA(lv_func_name).
    APPEND VALUE #( obj_type = 'FUNC' obj_name = lv_func_name ) TO ct_inventory.
  ENDLOOP.

  SELECT obj_name FROM tadir INTO TABLE @lt_fugr
    WHERE pgmid = 'R3TR' AND object = 'FUGR' AND devclass = @iv_package.
  LOOP AT lt_fugr INTO DATA(lv_fugr_name).
    lv_area = |SAPL{ lv_fugr_name }|.

    SELECT funcname FROM tfdir INTO TABLE @lt_fugr_funcs
      WHERE pname = @lv_area.

    LOOP AT lt_fugr_funcs INTO DATA(lv_fugr_func_name).
      IF lv_fugr_func_name NP 'Z*' AND lv_fugr_func_name NP 'Y*'.
        CONTINUE.
      ENDIF.
      APPEND VALUE #( obj_type = 'FUNC' obj_name = lv_fugr_func_name ) TO ct_inventory.
    ENDLOOP.
  ENDLOOP.

  SORT ct_inventory BY obj_type obj_name.
  DELETE ADJACENT DUPLICATES FROM ct_inventory COMPARING obj_type obj_name.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  BUILD_PACKAGE_NAME_INDEX
*&---------------------------------------------------------------------*
*       Same inventory, reshaped into three flat name tables for fast
*       per-type membership lookup (used by TRANSPORT_TOUCHES_PACKAGE).
*&---------------------------------------------------------------------*
FORM build_package_name_index USING iv_package TYPE devclass.
  DATA lt_inv TYPE tt_lld_obj.

  PERFORM build_package_inventory USING iv_package CHANGING lt_inv.

  CLEAR: gt_pkg_prog, gt_pkg_clas, gt_pkg_func.

  LOOP AT lt_inv INTO DATA(ls_inv).
    CASE ls_inv-obj_type.
      WHEN 'PROG'. APPEND ls_inv-obj_name TO gt_pkg_prog.
      WHEN 'CLAS'. APPEND ls_inv-obj_name TO gt_pkg_clas.
      WHEN 'FUNC'. APPEND ls_inv-obj_name TO gt_pkg_func.
    ENDCASE.
  ENDLOOP.

  SORT: gt_pkg_prog, gt_pkg_clas, gt_pkg_func.
ENDFORM.

*&=======================================================================*
*& FULL-run object list building (reuses the original tool's
*& single-object builders, unchanged, in a loop over the package's
*& current inventory)
*&=======================================================================*

*&---------------------------------------------------------------------*
*&      Form  BUILD_OBJECT_LIST_FROM_PACKAGE
*&---------------------------------------------------------------------*
*       Loops the package's current inventory through the SAME
*       single-object builders ZCR_AURA_CODE_EXTRACTOR already has
*       (BUILD_OBJECT_LIST_FROM_PROG/_CLASS/_FUNC, reused unchanged),
*       then ADD_CLASS_METHODS (also unchanged) expands every collected
*       class into its methods for the ALV.
*&---------------------------------------------------------------------*
FORM build_object_list_from_package USING iv_package TYPE devclass.
  DATA: lt_inventory TYPE tt_lld_obj,
        lv_prog      TYPE sy-repid,
        lv_clas      TYPE seoclsname,
        lv_func      TYPE rs38l_fnam.

  PERFORM build_package_inventory USING iv_package CHANGING lt_inventory.

  LOOP AT lt_inventory INTO DATA(ls_inv).
    CASE ls_inv-obj_type.
      WHEN 'PROG'.
        lv_prog = ls_inv-obj_name.
        PERFORM build_object_list_from_prog USING lv_prog.
      WHEN 'CLAS'.
        lv_clas = ls_inv-obj_name.
        PERFORM build_object_list_from_class USING lv_clas.
      WHEN 'FUNC'.
        lv_func = ls_inv-obj_name.
        PERFORM build_object_list_from_func USING lv_func.
    ENDCASE.
  ENDLOOP.

  PERFORM add_class_methods.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  BUILD_OBJECT_LIST_FROM_PROG   (REUSED unchanged)
*&---------------------------------------------------------------------*
FORM build_object_list_from_prog USING iv_prog TYPE sy-repid.
  DATA ls_e071 TYPE e071.

  SELECT SINGLE name, subc
    FROM trdir
    INTO @DATA(ls_trdir)
    WHERE name = @iv_prog.

  IF sy-subrc <> 0.
    MESSAGE |Program { iv_prog } does not exist or is inactive - skipped.| TYPE 'S' DISPLAY LIKE 'E'.
    RETURN.
  ENDIF.

  CASE ls_trdir-subc.
    WHEN 'I'.                            "Include
      ls_e071-pgmid  = 'LIMU'.
      ls_e071-object = 'REPS'.
    WHEN OTHERS.
      PERFORM add_program_includes USING iv_prog.
      CLEAR ls_e071.
      ls_e071-pgmid  = 'R3TR'.
      ls_e071-object = 'PROG'.
  ENDCASE.

  ls_e071-obj_name = iv_prog.
  APPEND ls_e071 TO gt_e071.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  ADD_PROGRAM_INCLUDES   (REUSED unchanged)
*&---------------------------------------------------------------------*
FORM add_program_includes USING iv_program TYPE sy-repid.
  DATA: lt_includes TYPE STANDARD TABLE OF sy-repid,
        ls_e071     TYPE e071.

  CALL FUNCTION 'RS_GET_ALL_INCLUDES'
    EXPORTING
      program      = iv_program
    TABLES
      includetab   = lt_includes
    EXCEPTIONS
      not_existent = 1
      no_program   = 2
      OTHERS       = 3.

  CHECK sy-subrc = 0.

  LOOP AT lt_includes ASSIGNING FIELD-SYMBOL(<fs_incl>).
    CLEAR ls_e071.
    ls_e071-pgmid    = 'LIMU'.
    ls_e071-object   = 'REPS'.
    ls_e071-obj_name = <fs_incl>.
    APPEND ls_e071 TO gt_e071.
  ENDLOOP.
ENDFORM.

*&      Form  ADD_CLASS_METHODS   (REUSED unchanged)
*&---------------------------------------------------------------------*
FORM add_class_methods.
  LOOP AT gt_e071 ASSIGNING FIELD-SYMBOL(<fs_class>) WHERE object = 'CLAS'.

*&---------------------------------------------------------------------*
*&      Form  CONVERT_E071_TO_LLD_HITS
*&---------------------------------------------------------------------*
*       Adapts GT_E071 (built above) into the same TT_TR_HIT shape the
*       transport-sync path produces, with TRKORR left blank (meaning
*       "full run, no TR context"), so both paths converge on the same
*       BUILD_UNIQUE_LLD_OBJECTS below.
*
*       Deliberately keeps bare CLAS rows (unlike the original tool's
*       CONVERT_E071_TO_MULTI_OBJ, which excludes them) - a class's own
*       row is what guarantees it still appears as a checkable/
*       extractable candidate even if it happens to have zero methods.
*&---------------------------------------------------------------------*
FORM convert_e071_to_lld_hits CHANGING ct_hits TYPE tt_tr_hit.
  CLEAR ct_hits.

  LOOP AT gt_e071 INTO DATA(ls_e071).
    APPEND VALUE #( pgmid = ls_e071-pgmid
                     object = ls_e071-object
                     obj_name = ls_e071-obj_name
                     trkorr = space ) TO ct_hits.
  ENDLOOP.
ENDFORM.

*&=======================================================================*
*& Incremental sync: qualifying transports + hit gathering
*&=======================================================================*

*&---------------------------------------------------------------------*
*&      Form  GATHER_QUALIFYING_TRANSPORTS
*&---------------------------------------------------------------------*
*       Finds every released transport newer than IV_LAST_HWM (by
*       AS4DATE/AS4TIME, not TRKORR sort order - transport numbers are
*       not reliably comparable as plain strings across a landscape),
*       then narrows to the subset that actually touches this package.
*
*       CV_NEW_HWM is the highest-timestamp transport CONSIDERED this
*       run (system-wide), not just the ones that touched the package -
*       this is deliberate: a transport that was checked and found not
*       to touch this package should never need re-checking on a future
*       run, or the HWM would never really advance past irrelevant
*       system activity.
*
*       VERIFY: this assumes E070-TRSTATUS = 'R' is this system's
*       "released" status value (the standard SAP convention). Some
*       landscapes use additional/different status codes - confirm
*       against a known-released transport before relying on this.
*&---------------------------------------------------------------------*
FORM gather_qualifying_transports USING iv_package  TYPE devclass
                                         iv_last_hwm TYPE e070-trkorr
                                   CHANGING ct_touching_trkorr TYPE tt_trkorr
                                            cv_new_hwm         TYPE e070-trkorr.
  DATA: lv_hwm_date TYPE e070-as4date,
        lv_hwm_time TYPE e070-as4time.

  CLEAR: ct_touching_trkorr, cv_new_hwm.

  IF iv_last_hwm IS NOT INITIAL.
    SELECT SINGLE as4date, as4time FROM e070
      INTO (@lv_hwm_date, @lv_hwm_time)
      WHERE trkorr = @iv_last_hwm.
  ENDIF.

  SELECT trkorr, as4date, as4time FROM e070
    INTO TABLE @DATA(lt_candidates)
    WHERE trstatus = 'R'
      AND ( as4date > @lv_hwm_date
            OR ( as4date = @lv_hwm_date AND as4time > @lv_hwm_time ) )
    ORDER BY as4date ASCENDING, as4time ASCENDING.

  CHECK lt_candidates IS NOT INITIAL.

  READ TABLE lt_candidates INTO DATA(ls_highest) INDEX lines( lt_candidates ).
  cv_new_hwm = ls_highest-trkorr.

  PERFORM build_package_name_index USING iv_package.

  DATA lv_touches TYPE abap_bool.

  LOOP AT lt_candidates INTO DATA(ls_cand).
    PERFORM transport_touches_package USING ls_cand-trkorr CHANGING lv_touches.
    IF lv_touches = abap_true.
      APPEND ls_cand-trkorr TO ct_touching_trkorr.
    ENDIF.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  TRANSPORT_TOUCHES_PACKAGE
*&---------------------------------------------------------------------*
*       E071 carries no DEVCLASS, so package membership can only be
*       checked via each hit's resolved owning object name against
*       GT_PKG_PROG/GT_PKG_CLAS/GT_PKG_FUNC (built by
*       BUILD_PACKAGE_NAME_INDEX before this is called in a loop).
*&---------------------------------------------------------------------*
FORM transport_touches_package USING iv_trkorr TYPE e070-trkorr
                                CHANGING cv_touches TYPE abap_bool.
  DATA: lt_subtask     TYPE STANDARD TABLE OF e070-trkorr,
        lr_trkorr      TYPE RANGE OF e070-trkorr,
        lt_e071        TYPE tt_e071,
        lv_owner_type  TYPE e071-object,
        lv_owner_name  TYPE e071-obj_name.

  cv_touches = abap_false.

  SELECT trkorr FROM e070 INTO TABLE @lt_subtask WHERE strkorr = @iv_trkorr.

  APPEND VALUE #( sign = 'I' option = 'EQ' low = iv_trkorr ) TO lr_trkorr.
  LOOP AT lt_subtask INTO DATA(lv_sub).
    APPEND VALUE #( sign = 'I' option = 'EQ' low = lv_sub ) TO lr_trkorr.
  ENDLOOP.

  SELECT * FROM e071 INTO TABLE lt_e071
    WHERE trkorr IN lr_trkorr
      AND pgmid  IN ('R3TR','LIMU')
      AND object IN ('PROG','REPS','METH','CLAS','CLSD','CPUB','CPRI','CPRO','FUNC').

  CHECK sy-subrc = 0.

  LOOP AT lt_e071 INTO DATA(ls_hit).
    DATA(ls_hit_shape) = VALUE ts_tr_hit( pgmid = ls_hit-pgmid
                                           object = ls_hit-object
                                           obj_name = ls_hit-obj_name ).
    PERFORM determine_owner USING ls_hit_shape
                             CHANGING lv_owner_type lv_owner_name.

    CASE lv_owner_type.
      WHEN 'PROG'.
        READ TABLE gt_pkg_prog TRANSPORTING NO FIELDS WITH KEY table_line = lv_owner_name BINARY SEARCH.
      WHEN 'CLAS'.
        READ TABLE gt_pkg_clas TRANSPORTING NO FIELDS WITH KEY table_line = lv_owner_name BINARY SEARCH.
      WHEN 'FUNC'.
        READ TABLE gt_pkg_func TRANSPORTING NO FIELDS WITH KEY table_line = lv_owner_name BINARY SEARCH.
      WHEN OTHERS.
        CONTINUE.
    ENDCASE.

    IF sy-subrc = 0.
      cv_touches = abap_true.
      RETURN.
    ENDIF.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  COLLECT_TR_HITS   (REUSED unchanged from ZCR_AURA_CODE_EXTRACTOR)
*&---------------------------------------------------------------------*
FORM collect_tr_hits USING iv_trkorr TYPE e070-trkorr
                     CHANGING ct_hits TYPE tt_tr_hit.
  DATA: lt_subtask TYPE STANDARD TABLE OF e070-trkorr,
        lt_e071    TYPE tt_e071.

  SELECT trkorr FROM e070 INTO TABLE lt_subtask WHERE strkorr = iv_trkorr.

  DATA(lr_subtask) = VALUE rseloption(
    FOR <fs_subtask> IN lt_subtask
    ( sign = 'I' option = 'EQ' low = <fs_subtask> ) ).

  CHECK lr_subtask IS NOT INITIAL.

  SELECT * FROM e071 INTO TABLE lt_e071
    WHERE trkorr IN lr_subtask
      AND pgmid  IN ('R3TR','LIMU')
      AND object IN ('PROG', 'REPS', 'METH', 'CLAS', 'CLSD', 'CPUB', 'CPRI', 'CPRO', 'FUNC', 'DOMA', 'DTEL', 'TABL', 'TTYP')
    ORDER BY pgmid object obj_name.

  CHECK sy-subrc = 0.

  DELETE ADJACENT DUPLICATES FROM lt_e071 COMPARING pgmid object obj_name.

  LOOP AT lt_e071 ASSIGNING FIELD-SYMBOL(<fs_e071>).
    APPEND VALUE #( pgmid    = <fs_e071>-pgmid
                     object   = <fs_e071>-object
                     obj_name = <fs_e071>-obj_name
                     trkorr   = iv_trkorr ) TO ct_hits.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  EXPAND_CLASS_METHODS   (REUSED unchanged from ZCR_AURA_CODE_EXTRACTOR)
*&---------------------------------------------------------------------*
FORM expand_class_methods CHANGING ct_hits TYPE tt_tr_hit.
  DATA: lt_clas_hits  TYPE tt_tr_hit,
        lr_class_name TYPE RANGE OF seoclsname,
        lt_new_hits   TYPE tt_tr_hit.

  lt_clas_hits = VALUE #( FOR ls_hit IN ct_hits WHERE ( object = 'CLAS' ) ( ls_hit ) ).
  CHECK lt_clas_hits IS NOT INITIAL.

  lr_class_name = VALUE #( FOR ls_clas IN lt_clas_hits
                            ( sign = 'I' option = 'EQ' low = ls_clas-obj_name ) ).

  SELECT clsname, cmpname
    INTO TABLE @DATA(lt_methods)
    FROM seocompo
   WHERE clsname IN @lr_class_name
     AND cmptype = '1'.

  CHECK sy-subrc = 0.

  LOOP AT lt_methods INTO DATA(ls_meth).
    LOOP AT lt_clas_hits INTO DATA(ls_clas_hit) WHERE obj_name = ls_meth-clsname.
      APPEND VALUE #( pgmid    = 'LIMU'
                       object   = 'METH'
                       obj_name = |{ ls_meth-clsname WIDTH = 30 }{ ls_meth-cmpname }|
                       trkorr   = ls_clas_hit-trkorr ) TO lt_new_hits.
    ENDLOOP.
  ENDLOOP.

  APPEND LINES OF lt_new_hits TO ct_hits.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  DETERMINE_OWNER
*&---------------------------------------------------------------------*
*       Maps any single E071-shaped hit to the whole top-level LLD
*       object it belongs to. Used three ways: (1) rolling up ALV
*       fragments to whole objects, (2) the package-membership check in
*       TRANSPORT_TOUCHES_PACKAGE, (3) implicitly via both of those for
*       both FULL and INCR runs. DOMA/DTEL/TABL/TTYP (and anything
*       unrecognized) return a blank owner - the shared DDIC section
*       handles those separately (see BUILD_PACKAGE_DDIC_JSON), always
*       rebuilt fresh from the package's live TADIR, not tracked here.
*&---------------------------------------------------------------------*
FORM determine_owner USING is_hit TYPE ts_tr_hit
                      CHANGING cv_owner_type TYPE e071-object
                               cv_owner_name TYPE e071-obj_name.
  DATA: lv_classname  TYPE seoclsname,
        lv_methodname TYPE string,
        lv_obj        TYPE string,
        lv_master     TYPE progname.

  CLEAR: cv_owner_type, cv_owner_name.

  CASE is_hit-object.
    WHEN 'PROG'.
      cv_owner_type = 'PROG'.
      cv_owner_name = is_hit-obj_name.

    WHEN 'REPS'.
      cv_owner_type = 'PROG'.

      SELECT SINGLE master FROM d010inc INTO @lv_master WHERE include = @is_hit-obj_name.
      IF sy-subrc = 0 AND lv_master IS NOT INITIAL.
        cv_owner_name = lv_master.
      ELSE.
        " VERIFY: no D010INC row means either this include has no
        " separately-tracked master (it IS the main program), or the
        " program simply has zero other includes - falling back to the
        " include's own name as the owner in that case.
        cv_owner_name = is_hit-obj_name.
      ENDIF.

    WHEN 'CLAS' OR 'CLSD' OR 'CPUB' OR 'CPRI' OR 'CPRO'.
      cv_owner_type = 'CLAS'.
      cv_owner_name = is_hit-obj_name.

    WHEN 'METH'.
      cv_owner_type = 'CLAS'.
      lv_obj = is_hit-obj_name.
      CONDENSE lv_obj.
      SPLIT lv_obj AT space INTO lv_classname lv_methodname.
      cv_owner_name = lv_classname.

    WHEN 'FUNC'.
      cv_owner_type = 'FUNC'.
      cv_owner_name = is_hit-obj_name.

    WHEN OTHERS.
      CLEAR: cv_owner_type, cv_owner_name.
  ENDCASE.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  BUILD_UNIQUE_LLD_OBJECTS
*&---------------------------------------------------------------------*
*       Deduplicates IT_HITS by (object, obj_name) into
*       GT_LLD_MULTI_OBJ, one ALV row per unique fragment, each
*       resolved to its owning whole object via DETERMINE_OWNER.
*       Fragments with no resolvable owner (DOMA/DTEL/TABL/TTYP) are
*       dropped - they have no LLD object-block home.
*&---------------------------------------------------------------------*
FORM build_unique_lld_objects USING it_hits TYPE tt_tr_hit.
  DATA: lt_unique     TYPE tt_tr_hit,
        ls_multi      TYPE ts_lld_multi_obj,
        lv_owner_type TYPE e071-object,
        lv_owner_name TYPE e071-obj_name.

  CLEAR gt_lld_multi_obj.

  lt_unique = it_hits.
  SORT lt_unique BY object obj_name.
  DELETE ADJACENT DUPLICATES FROM lt_unique COMPARING object obj_name.

  LOOP AT lt_unique INTO DATA(ls_unique).
    PERFORM determine_owner USING ls_unique CHANGING lv_owner_type lv_owner_name.
    CHECK lv_owner_type IS NOT INITIAL.

    CLEAR ls_multi.
    ls_multi-checked     = abap_true.
    ls_multi-pgmid       = ls_unique-pgmid.
    ls_multi-object      = ls_unique-object.
    ls_multi-obj_name    = ls_unique-obj_name.
    ls_multi-obj_display = |{ ls_unique-obj_name } { ls_unique-object }|.
    ls_multi-owner_type  = lv_owner_type.
    ls_multi-owner_name  = lv_owner_name.

    IF gv_run_type = 'INCR'.
      PERFORM build_tr_list USING ls_unique-object ls_unique-obj_name it_hits
                             CHANGING ls_multi-tr_list ls_multi-most_recent_tr.
    ENDIF.

    APPEND ls_multi TO gt_lld_multi_obj.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  BUILD_TR_LIST   (REUSED unchanged from ZCR_AURA_CODE_EXTRACTOR)
*&---------------------------------------------------------------------*
FORM build_tr_list USING iv_object    TYPE e071-object
                          iv_obj_name TYPE e071-obj_name
                          it_hits     TYPE tt_tr_hit
                   CHANGING cv_tr_list       TYPE string
                            cv_most_recent   TYPE e070-trkorr.
  DATA: lt_matching  TYPE STANDARD TABLE OF e070-trkorr,
        lt_e070      TYPE STANDARD TABLE OF ts_e070_recency,
        ls_e070      TYPE ts_e070_recency,
        lv_best_date TYPE e070-as4date,
        lv_best_time TYPE e070-as4time.

  CLEAR: cv_tr_list, cv_most_recent, lv_best_date, lv_best_time.

  LOOP AT it_hits INTO DATA(ls_hit) WHERE object = iv_object AND obj_name = iv_obj_name.
    APPEND ls_hit-trkorr TO lt_matching.
    IF cv_tr_list IS INITIAL.
      cv_tr_list = ls_hit-trkorr.
    ELSE.
      cv_tr_list = |{ cv_tr_list }, { ls_hit-trkorr }|.
    ENDIF.
  ENDLOOP.

  CHECK lt_matching IS NOT INITIAL.

  SELECT trkorr, as4date, as4time
    INTO TABLE @lt_e070
    FROM e070
    FOR ALL ENTRIES IN @lt_matching
   WHERE trkorr = @lt_matching-table_line.

  LOOP AT lt_e070 INTO ls_e070.
    IF cv_most_recent IS INITIAL
    OR ls_e070-as4date > lv_best_date
    OR ( ls_e070-as4date = lv_best_date AND ls_e070-as4time > lv_best_time ).
      cv_most_recent = ls_e070-trkorr.
      lv_best_date   = ls_e070-as4date.
      lv_best_time   = ls_e070-as4time.
    ENDIF.
  ENDLOOP.
ENDFORM.

*&=======================================================================*
*& Deletion detection
*&=======================================================================*

*&---------------------------------------------------------------------*
*&      Form  DETECT_REMOVED_OBJECTS
*&---------------------------------------------------------------------*
FORM detect_removed_objects USING iv_package TYPE devclass
                                   it_current TYPE tt_lld_obj
                             CHANGING ct_removed TYPE tt_lld_obj.
  DATA lt_stored TYPE tt_lld_obj.

  CLEAR ct_removed.

  SELECT obj_type, obj_name FROM zdccrt_sync_obj
    INTO TABLE @lt_stored
    WHERE zpackage = @iv_package.

  IF sy-subrc <> 0.
    RETURN.   " first run - nothing stored yet, nothing can be "removed"
  ENDIF.

  LOOP AT lt_stored INTO DATA(ls_stored).
    READ TABLE it_current TRANSPORTING NO FIELDS
      WITH KEY obj_type = ls_stored-obj_type obj_name = ls_stored-obj_name.
    IF sy-subrc <> 0.
      APPEND ls_stored TO ct_removed.
    ENDIF.
  ENDLOOP.

  SORT ct_removed BY obj_type obj_name.
ENDFORM.

*&=======================================================================*
*& Whole-object extraction (dependency JSON + source + LLD block)
*&=======================================================================*

*&---------------------------------------------------------------------*
*&      Form  PROCESS_CHECKED_LLD_OBJECTS
*&---------------------------------------------------------------------*
*       Rolls up every checked ALV fragment to its owning whole object
*       (any owner with >=1 checked fragment is extracted once), then
*       extracts each distinct owner.
*&---------------------------------------------------------------------*
FORM process_checked_lld_objects.
  DATA lt_owners TYPE tt_lld_obj.

  gv_extracted_count = 0.

  LOOP AT gt_lld_multi_obj INTO DATA(ls_multi) WHERE checked = abap_true.
    APPEND VALUE #( obj_type = ls_multi-owner_type obj_name = ls_multi-owner_name ) TO lt_owners.
  ENDLOOP.

  SORT lt_owners BY obj_type obj_name.
  DELETE ADJACENT DUPLICATES FROM lt_owners COMPARING obj_type obj_name.

  LOOP AT lt_owners INTO DATA(ls_owner).
    PERFORM extract_lld_object USING ls_owner-obj_type ls_owner-obj_name.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  EXTRACT_LLD_OBJECT
*&---------------------------------------------------------------------*
FORM extract_lld_object USING iv_owner_type TYPE e071-object
                               iv_owner_name TYPE e071-obj_name.
  DATA: lv_lld_type TYPE string,
        lt_source   TYPE tt_code_line,
        lv_dep_json TYPE string,
        lv_skip     TYPE abap_bool.

  CASE iv_owner_type.
    WHEN 'PROG'. lv_lld_type = 'PROGRAM'.
    WHEN 'CLAS'. lv_lld_type = 'CLASS'.
    WHEN 'FUNC'. lv_lld_type = 'FUNCTION_MODULE'.
    WHEN OTHERS. RETURN.
  ENDCASE.

  PERFORM get_source_for_lld_object USING iv_owner_type iv_owner_name
                                     CHANGING lt_source lv_skip.
  CHECK lv_skip = abap_false.

  PERFORM build_dependency_for_object USING iv_owner_type iv_owner_name
                                           CHANGING lv_dep_json lv_skip.
  CHECK lv_skip = abap_false.

  PERFORM append_lld_object_block USING lv_lld_type iv_owner_name p_pack lt_source lv_dep_json.
  gv_extracted_count = gv_extracted_count + 1.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  GET_SOURCE_FOR_LLD_OBJECT
*&---------------------------------------------------------------------*
*       Current ACTIVE source only - no diff, no version selection.
*       PROG and CLAS both go through READ_PROGRAM_AND_INCLUDES (main
*       program + every RS_GET_ALL_INCLUDES result, same FM
*       ADD_PROGRAM_INCLUDES already uses) - CLAS resolves its
*       classpool's own program name first via CL_OO_CLASSNAME_SERVICE.
*       FUNC resolves its own include via FUNCTION_INCLUDE_INFO (same
*       technique the original BUILD_DEPENDENCY_INPUT uses) and reads
*       just that one include.
*&---------------------------------------------------------------------*
FORM get_source_for_lld_object USING iv_owner_type TYPE e071-object
                                      iv_owner_name TYPE e071-obj_name
                                CHANGING ct_source TYPE tt_code_line
                                         cv_skip   TYPE abap_bool.
  DATA: lv_progname   TYPE progname,
        lv_clsname    TYPE seoclsname,
        lv_classpool  TYPE progname,
        lv_fm_name    TYPE rs38l_fnam,
        lv_fm_include TYPE progname.

  CLEAR: ct_source, cv_skip.

  CASE iv_owner_type.
    WHEN 'PROG'.
      lv_progname = iv_owner_name.
      PERFORM read_program_and_includes USING lv_progname CHANGING ct_source cv_skip.

    WHEN 'CLAS'.
      lv_clsname = iv_owner_name.

      " A class's compiled "classpool" is itself a PROG-type object that
      " INCLUDEs the definition, public/protected/private sections, and
      " every method's own include - reading it the same way a PROG
      " object is read (main program + every RS_GET_ALL_INCLUDES result)
      " gives back the whole class source, without needing a
      " class-source-specific FM (SEO_CLASS_GET_SOURCE does not exist on
      " every release - confirmed absent on this system).
      " VERIFY: CL_OO_CLASSNAME_SERVICE=>GET_CLASSPOOL_NAME is assumed to
      " exist as a sibling of GET_PUBSEC_NAME/GET_PRISEC_NAME/
      " GET_PROSEC_NAME/GET_CCDEF_NAME, which ZCR_AURA_CODE_EXTRACTOR's
      " own BUILD_DEPENDENCY_INPUT already calls successfully on this
      " system - if this specific method is also missing, RS_GET_ALL_
      " INCLUDES can resolve the same classpool name another way (e.g.
      " reading it off any one of the section include names it already
      " returns via TRDIR/D010INC, since they all share one master).
      lv_classpool = cl_oo_classname_service=>get_classpool_name( lv_clsname ).
      PERFORM read_program_and_includes USING lv_classpool CHANGING ct_source cv_skip.

    WHEN 'FUNC'.
      lv_fm_name = iv_owner_name.

      CALL FUNCTION 'FUNCTION_INCLUDE_INFO'
        CHANGING
          funcname            = lv_fm_name
          include             = lv_fm_include
        EXCEPTIONS
          function_not_exists = 1
          include_not_exists  = 2
          group_not_exists    = 3
          no_selections       = 4
          no_function_include = 5
          OTHERS              = 6.

      IF sy-subrc <> 0.
        cv_skip = abap_true.
        RETURN.
      ENDIF.

      PERFORM read_single_program_source USING lv_fm_include CHANGING ct_source cv_skip.

    WHEN OTHERS.
      cv_skip = abap_true.
  ENDCASE.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  READ_PROGRAM_AND_INCLUDES
*&---------------------------------------------------------------------*
*       Reads a main program's own source plus every include
*       RS_GET_ALL_INCLUDES returns for it, concatenated in that order.
*       Used directly for PROG objects, and for CLAS objects via their
*       resolved classpool name (see GET_SOURCE_FOR_LLD_OBJECT) - a
*       class's compiled classpool program INCLUDEs its definition,
*       public/protected/private sections, and every method's own
*       include, so this one routine covers both object types.
*&---------------------------------------------------------------------*
FORM read_program_and_includes USING iv_progname TYPE progname
                                CHANGING ct_source TYPE tt_code_line
                                         cv_skip   TYPE abap_bool.
  DATA lt_includes TYPE STANDARD TABLE OF sy-repid.

  CLEAR: ct_source, cv_skip.

  PERFORM read_single_program_source USING iv_progname CHANGING ct_source cv_skip.
  CHECK cv_skip = abap_false.

  CALL FUNCTION 'RS_GET_ALL_INCLUDES'
    EXPORTING
      program      = iv_progname
    TABLES
      includetab   = lt_includes
    EXCEPTIONS
      not_existent = 1
      no_program   = 2
      OTHERS       = 3.

  IF sy-subrc = 0.
    LOOP AT lt_includes INTO DATA(lv_incl).
      DATA(lt_incl_source) = VALUE tt_code_line( ).
      DATA(lv_incl_skip)   = abap_false.
      PERFORM read_single_program_source USING lv_incl CHANGING lt_incl_source lv_incl_skip.
      IF lv_incl_skip = abap_false.
        APPEND LINES OF lt_incl_source TO ct_source.
      ENDIF.
    ENDLOOP.
  ENDIF.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  READ_SINGLE_PROGRAM_SOURCE
*&---------------------------------------------------------------------*
*       Confirmed against this system's actual RPY_PROGRAM_READ
*       signature (SE37): no STATE parameter exists. READ_LATEST_VERSION
*       (TYPE PROGDIR-STATE, default SPACE) is the real equivalent -
*       'A' is the standard SAP convention for "active version," passed
*       explicitly here since this report always wants current active
*       source, never whatever SPACE's default behavior resolves to.
*       SOURCE_EXTENDED (TABLES, LIKE ABAPTXT255) is confirmed to exist
*       with that exact name; its line type is assumed flat C(255),
*       matching TS_LINE_255 and the same convention already used
*       elsewhere in this codebase for SVRS_GET_REPS_FROM_OBJECT's
*       REPOS_TAB - if source comes back garbled, ABAPTXT255's real line
*       type is the first thing to check.
*&---------------------------------------------------------------------*
FORM read_single_program_source USING iv_progname TYPE progname
                                 CHANGING ct_source TYPE tt_code_line
                                          cv_skip   TYPE abap_bool.
  DATA: lt_source_raw TYPE STANDARD TABLE OF ts_line_255.

  CLEAR: ct_source, cv_skip.

  CALL FUNCTION 'RPY_PROGRAM_READ'
    EXPORTING
      program_name        = iv_progname
      read_latest_version = 'A'
    TABLES
      source_extended     = lt_source_raw
    EXCEPTIONS
      cancelled           = 1
      not_found           = 2
      permission_error    = 3
      OTHERS              = 4.

  IF sy-subrc <> 0.
    cv_skip = abap_true.
    RETURN.
  ENDIF.

  LOOP AT lt_source_raw INTO DATA(ls_raw).
    APPEND VALUE #( line = ls_raw ) TO ct_source.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  BUILD_DEPENDENCY_FOR_OBJECT
*&---------------------------------------------------------------------*
*       Calls ZCR_GET_DEPENDENCY_OBJ_NEW exactly as the existing report
*       does, per object type:
*         PROG -> obj_type='PROG', the program's own name (its own
*                 REPOSITORY_ENVIRONMENT_RFC-based branch).
*         CLAS -> obj_type='CLAS', the class's own name. NOTE: this
*                 branch's real behavior is an inventory of the class's
*                 OWN methods + implemented interfaces (via SEOCOMPO/
*                 SEOMETAREL), not "what this class calls externally" -
*                 that's the FM's actual existing behavior, reused
*                 as-is, not something this report changes or works
*                 around.
*         FUNC -> ZCR_GET_DEPENDENCY_OBJ_NEW has no native FUNC branch.
*                 Resolves the FM's own include via FUNCTION_INCLUDE_INFO
*                 first (same translation BUILD_DEPENDENCY_INPUT already
*                 performs) and calls with obj_type='PROG' on that
*                 include - this is what actually yields "what this
*                 function module calls."
*
*       Each call's own EV_DDIC_JSON is intentionally discarded - the
*       file's single shared DDIC section comes from
*       BUILD_PACKAGE_DDIC_JSON instead (package-scoped, not
*       object-referenced-scoped), per the brief's "one shared DDIC
*       section, not duplicated per object" requirement.
*&---------------------------------------------------------------------*
FORM build_dependency_for_object USING iv_owner_type TYPE e071-object
                                            iv_owner_name TYPE e071-obj_name
                                      CHANGING cv_dep_json TYPE string
                                               cv_skip     TYPE abap_bool.
  DATA: lt_dep_input  TYPE zpoc_tt_obj,
        lv_dummy_ddic TYPE string,
        lv_fm_name    TYPE rs38l_fnam,
        lv_fm_include TYPE progname.

  CLEAR: cv_dep_json, cv_skip, lt_dep_input.

  CASE iv_owner_type.
    WHEN 'PROG'.
      APPEND VALUE #( obj_type = 'PROG' object_name = iv_owner_name ) TO lt_dep_input.

    WHEN 'CLAS'.
      APPEND VALUE #( obj_type = 'CLAS' object_name = iv_owner_name ) TO lt_dep_input.

    WHEN 'FUNC'.
      lv_fm_name = iv_owner_name.

      CALL FUNCTION 'FUNCTION_INCLUDE_INFO'
        CHANGING
          funcname            = lv_fm_name
          include             = lv_fm_include
        EXCEPTIONS
          function_not_exists = 1
          include_not_exists  = 2
          group_not_exists    = 3
          no_selections       = 4
          no_function_include = 5
          OTHERS              = 6.

      IF sy-subrc <> 0.
        cv_skip = abap_true.
        RETURN.
      ENDIF.

      APPEND VALUE #( obj_type = 'PROG' object_name = lv_fm_include ) TO lt_dep_input.

    WHEN OTHERS.
      cv_skip = abap_true.
      RETURN.
  ENDCASE.

  CALL FUNCTION 'ZCR_GET_DEPENDENCY_OBJ_NEW'
    EXPORTING
      ii_objects   = lt_dep_input
    IMPORTING
      ev_json      = cv_dep_json
      ev_ddic_json = lv_dummy_ddic.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  BUILD_PACKAGE_DDIC_JSON
*&---------------------------------------------------------------------*
*       ONE call to Z_GET_DDIC_INFO, covering every DOMA/DTEL/TABL/TTYP
*       that belongs to the package itself (via TADIR), independent of
*       which specific objects got extracted this run. This is the
*       file's single shared --- DDIC --- section.
*&---------------------------------------------------------------------*
FORM build_package_ddic_json USING iv_package TYPE devclass
                              CHANGING cv_ddic_json TYPE string.
  DATA lt_ddic_objs TYPE zpoc_tt_ddic_obj.

  CLEAR cv_ddic_json.

  SELECT object, obj_name FROM tadir
    INTO TABLE @DATA(lt_tadir)
    WHERE pgmid = 'R3TR' AND devclass = @iv_package
      AND object IN ('DOMA','DTEL','TABL','TTYP').

  CHECK sy-subrc = 0.

  LOOP AT lt_tadir INTO DATA(ls_tadir).
    APPEND VALUE #( obj_type = ls_tadir-object object_name = ls_tadir-obj_name ) TO lt_ddic_objs.
  ENDLOOP.

  CHECK lt_ddic_objs IS NOT INITIAL.

  CALL FUNCTION 'Z_GET_DDIC_INFO'
    EXPORTING
      ii_objects = lt_ddic_objs
    IMPORTING
      ew_json    = cv_ddic_json.
ENDFORM.

*&=======================================================================*

*&---------------------------------------------------------------------*
*&      Form  BUILD_AND_WRITE_LLD_FILE
*&---------------------------------------------------------------------*
FORM build_and_write_lld_file.
  DATA lv_ddic_json TYPE string.

  CLEAR gt_output.

  PERFORM build_package_ddic_json USING p_pack CHANGING lv_ddic_json.
  PERFORM append_file_header USING p_pack gv_run_type gt_removed_objects lv_ddic_json.
  PERFORM process_checked_lld_objects.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  BUILD_REMOVED_OBJECTS_LIST
*&---------------------------------------------------------------------*
*       Extracted out of APPEND_FILE_HEADER unchanged (pure refactor -
*       same loop, same string building, same output) so DB mode's
*       ZLLD_STG_RUN-REMOVED_OBJECTS can share the exact same
*       "TYPE:NAME, TYPE:NAME" / "NONE" format as the file header line,
*       without file mode's own output changing by a single character.
*&---------------------------------------------------------------------*
FORM build_removed_objects_list USING it_removed TYPE tt_lld_obj
                                 CHANGING cv_list TYPE string.
  CLEAR cv_list.

  IF it_removed IS INITIAL.
    cv_list = 'NONE'.
  ELSE.
    LOOP AT it_removed INTO DATA(ls_removed).
      IF cv_list IS INITIAL.
        cv_list = |{ ls_removed-obj_type }:{ ls_removed-obj_name }|.
      ELSE.
        cv_list = |{ cv_list }, { ls_removed-obj_type }:{ ls_removed-obj_name }|.
      ENDIF.
    ENDLOOP.
  ENDIF.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  APPEND_FILE_HEADER
*&---------------------------------------------------------------------*
*       Written ONCE, before any object blocks. REMOVED_OBJECTS is a
*       comma-separated "TYPE:NAME" list, or NONE - step 2's loader
*       needs this explicit list to prune objects the graph/vector
*       store, since a scoped sync's silence about an object is not
*       itself a deletion signal.
*&---------------------------------------------------------------------*
FORM append_file_header USING iv_package   TYPE devclass
                               iv_run_type  TYPE char4
                               it_removed   TYPE tt_lld_obj
                               iv_ddic_json TYPE string.
  DATA lv_removed_list TYPE string.

  PERFORM build_removed_objects_list USING it_removed CHANGING lv_removed_list.

  APPEND VALUE #( line = |RUN_TYPE: { iv_run_type }| ) TO gt_output.
  APPEND VALUE #( line = |PACKAGE: { iv_package }| ) TO gt_output.
  APPEND VALUE #( line = |EXTRACTED_AT: { sy-datum DATE = ISO } { sy-uzeit TIME = ISO }| ) TO gt_output.
  APPEND VALUE #( line = |REMOVED_OBJECTS: { lv_removed_list }| ) TO gt_output.
  APPEND VALUE #( line = | | ) TO gt_output.
  APPEND VALUE #( line = |--- DDIC ---| ) TO gt_output.
  APPEND VALUE #( line = iv_ddic_json ) TO gt_output.
  APPEND VALUE #( line = | | ) TO gt_output.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  APPEND_LLD_OBJECT_BLOCK
*&---------------------------------------------------------------------*
FORM append_lld_object_block USING iv_lld_type TYPE string
                                    iv_obj_name TYPE e071-obj_name
                                    iv_package  TYPE devclass
                                    it_source   TYPE tt_code_line
                                    iv_dep_json TYPE string.
  APPEND VALUE #( line = |=== OBJECT: { iv_obj_name } ===| ) TO gt_output.
  APPEND VALUE #( line = |TYPE: { iv_lld_type }| ) TO gt_output.
  APPEND VALUE #( line = |PACKAGE: { iv_package }| ) TO gt_output.
  APPEND VALUE #( line = | | ) TO gt_output.
  APPEND VALUE #( line = |--- SOURCE ---| ) TO gt_output.

  LOOP AT it_source INTO DATA(ls_source).
    APPEND VALUE #( line = ls_source-line ) TO gt_output.
  ENDLOOP.

  APPEND VALUE #( line = | | ) TO gt_output.
  APPEND VALUE #( line = |--- DEPENDENCIES ---| ) TO gt_output.
  APPEND VALUE #( line = iv_dep_json ) TO gt_output.
  APPEND VALUE #( line = |=== END OBJECT ===| ) TO gt_output.
  APPEND VALUE #( line = | | ) TO gt_output.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  CONFIRM_OVERWRITE_IF_EXISTS   (REUSED unchanged)
*&---------------------------------------------------------------------*
FORM confirm_overwrite_if_exists CHANGING cv_proceed TYPE abap_bool.
  DATA: lv_exists TYPE abap_bool,
        lv_answer TYPE c LENGTH 1.

  cv_proceed = abap_true.

  cl_gui_frontend_services=>file_exist(
    EXPORTING
      file   = gv_full_path
    RECEIVING
      result = lv_exists
    EXCEPTIONS
      OTHERS = 1 ).

  CHECK lv_exists = abap_true.

  CALL FUNCTION 'POPUP_TO_CONFIRM'
    EXPORTING
      titlebar       = 'File Already Exists'
      text_question  = |{ gv_full_path } already exists. Overwrite it?|
      text_button_1  = 'Yes'
      text_button_2  = 'No'
      default_button = '2'
    IMPORTING
      answer         = lv_answer
    EXCEPTIONS
      text_not_found = 1
      OTHERS         = 2.

  IF lv_answer <> '1'.
    cv_proceed = abap_false.
  ENDIF.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  DOWNLOAD_OUTPUT_FILE   (REUSED unchanged)
*&---------------------------------------------------------------------*
FORM download_output_file.
  DATA lv_proceed TYPE abap_bool.

  PERFORM confirm_overwrite_if_exists CHANGING lv_proceed.
  IF lv_proceed = abap_false.
    WRITE: / 'Download cancelled - existing file was not overwritten.'.
    RETURN.
  ENDIF.

  CALL FUNCTION 'GUI_DOWNLOAD'
    EXPORTING
      filename         = gv_full_path
      filetype         = 'ASC'
    TABLES
      data_tab         = gt_output
    EXCEPTIONS
      file_write_error = 1
      OTHERS           = 2.

  IF sy-subrc = 0.
    WRITE: / 'File successfully downloaded to:', gv_full_path.
  ELSE.
    WRITE: / 'Error downloading file. Check if the file path is valid.'.
  ENDIF.
ENDFORM.

*&=======================================================================*
*& DB-mode output (step1_db_mode_brief.md)
*&
*& Stages the SAME already-computed data FILE mode writes to GT_OUTPUT -
*& instead as rows in ZLLD_STG_RUN/_OBJECT/_DEPENDENCY/_DDIC - then hands
*& off to EXTRACT_TO_DB (real logic, defined in the included
*& Step 1/Include ZLLD_EXTRACT_TO_DB_F01.txt - see the INCLUDE statement
*& near the top of this report). This report's own staging forms below
*& still do not derive EDGE_KIND or otherwise interpret DEPENDENCY_TYPE
*& - that stays EXTRACT_TO_DB's job, unchanged from the original design.
*&
*& EXTRACT_LLD_OBJECT_DB and PROCESS_CHECKED_LLD_OBJECTS_DB below are
*& deliberate near-duplicates of EXTRACT_LLD_OBJECT/
*& PROCESS_CHECKED_LLD_OBJECTS rather than a shared, branching form -
*& the brief's "do not touch any existing extraction logic" is honored
*& most literally by never adding a conditional into those forms at all,
*& even at the cost of a small amount of duplicated owner-rollup logic.
*&=======================================================================*

*&---------------------------------------------------------------------*
*&      Form  GENERATE_RUN_ID
*&---------------------------------------------------------------------*
*       CL_SYSTEM_UUID is a stable, universally-available kernel-level
*       utility class (unlike /UI2/CL_JSON or similar add-on-dependent
*       classes) - no VERIFY needed here.
*&---------------------------------------------------------------------*
FORM generate_run_id CHANGING cv_run_id TYPE sysuuid_x16.
  TRY.
      cv_run_id = cl_system_uuid=>create_uuid_x16_static( ).
    CATCH cx_uuid_error.
      CLEAR cv_run_id.
  ENDTRY.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  BUILD_AND_STAGE_LLD_DB
*&---------------------------------------------------------------------*
*       DB-mode mirror of BUILD_AND_WRITE_LLD_FILE. Calls the SAME
*       BUILD_PACKAGE_DDIC_JSON (one Z_GET_DDIC_INFO call, not two) and
*       stages its result instead of appending it to GT_OUTPUT as text.
*&---------------------------------------------------------------------*
FORM build_and_stage_lld_db.
  DATA lv_ddic_json TYPE string.

  gv_extracted_count = 0.

  PERFORM build_package_ddic_json USING p_pack CHANGING lv_ddic_json.
  PERFORM stage_extraction_run USING gv_run_id p_pack gv_run_type gt_removed_objects.
  PERFORM stage_package_ddic USING gv_run_id lv_ddic_json.
  PERFORM process_checked_lld_objects_db.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  STAGE_EXTRACTION_RUN
*&---------------------------------------------------------------------*
FORM stage_extraction_run USING iv_run_id   TYPE sysuuid_x16
                                 iv_package  TYPE devclass
                                 iv_run_type TYPE char4
                                 it_removed  TYPE tt_lld_obj.
  DATA: ls_stg_run TYPE zdccrt_stg_run,
        lv_ts      TYPE timestampl.

  " ZDCCRT_STG_RUN-EXTRACTED_AT was built as TIMESTAMPL (long form, with
  " fractional seconds - same data element ZDCCRT_SYNC_LOG-LAST_SYNC_TS
  " already uses), not the plain TIMESTAMP originally proposed - LV_TS
  " matches that real field type so GET TIME STAMP FIELD populates it
  " correctly rather than relying on an implicit TIMESTAMP->TIMESTAMPL
  " conversion.
  GET TIME STAMP FIELD lv_ts.

  ls_stg_run-run_id       = iv_run_id.
  ls_stg_run-zpackage     = iv_package.
  ls_stg_run-run_type     = iv_run_type.
  ls_stg_run-extracted_at = lv_ts.
  PERFORM build_removed_objects_list USING it_removed CHANGING ls_stg_run-removed_objects.
  ls_stg_run-status       = 'EXTRACTED'.

  INSERT zdccrt_stg_run FROM ls_stg_run.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  PROCESS_CHECKED_LLD_OBJECTS_DB
*&---------------------------------------------------------------------*
*       Deliberate near-duplicate of PROCESS_CHECKED_LLD_OBJECTS - see
*       this section's header comment for why.
*&---------------------------------------------------------------------*
FORM process_checked_lld_objects_db.
  DATA lt_owners TYPE tt_lld_obj.

  gv_extracted_count = 0.

  LOOP AT gt_lld_multi_obj INTO DATA(ls_multi) WHERE checked = abap_true.
    APPEND VALUE #( obj_type = ls_multi-owner_type obj_name = ls_multi-owner_name ) TO lt_owners.
  ENDLOOP.

  SORT lt_owners BY obj_type obj_name.
  DELETE ADJACENT DUPLICATES FROM lt_owners COMPARING obj_type obj_name.

  LOOP AT lt_owners INTO DATA(ls_owner).
    PERFORM extract_lld_object_db USING ls_owner-obj_type ls_owner-obj_name.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  EXTRACT_LLD_OBJECT_DB
*&---------------------------------------------------------------------*
*       Deliberate near-duplicate of EXTRACT_LLD_OBJECT - calls the SAME
*       GET_SOURCE_FOR_LLD_OBJECT/BUILD_DEPENDENCY_FOR_OBJECT (unchanged,
*       untouched), then stages instead of appending text. Stores the
*       short OWNER_TYPE code (CLAS/PROG/FUNC) as OBJECT_TYPE, per the
*       brief's staging-table spec - not the long LLD_TYPE name
*       (PROGRAM/CLASS/FUNCTION_MODULE) file mode's output uses.
*&---------------------------------------------------------------------*
FORM extract_lld_object_db USING iv_owner_type TYPE e071-object
                                  iv_owner_name TYPE e071-obj_name.
  DATA: lt_source   TYPE tt_code_line,
        lv_dep_json TYPE string,
        lv_skip     TYPE abap_bool.

  CASE iv_owner_type.
    WHEN 'PROG' OR 'CLAS' OR 'FUNC'.
      " valid - fall through
    WHEN OTHERS.
      RETURN.
  ENDCASE.

  PERFORM get_source_for_lld_object USING iv_owner_type iv_owner_name
                                     CHANGING lt_source lv_skip.
  CHECK lv_skip = abap_false.

  PERFORM build_dependency_for_object USING iv_owner_type iv_owner_name
                                           CHANGING lv_dep_json lv_skip.
  CHECK lv_skip = abap_false.

  PERFORM stage_lld_object USING gv_run_id iv_owner_type iv_owner_name p_pack lt_source lv_dep_json.
  gv_extracted_count = gv_extracted_count + 1.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  STAGE_LLD_OBJECT
*&---------------------------------------------------------------------*
FORM stage_lld_object USING iv_run_id   TYPE sysuuid_x16
                             iv_obj_type TYPE e071-object
                             iv_obj_name TYPE e071-obj_name
                             iv_package  TYPE devclass
                             it_source   TYPE tt_code_line
                             iv_dep_json TYPE string.
  DATA ls_stg_object TYPE zdccrt_stg_obj.

  ls_stg_object-run_id   = iv_run_id.
  ls_stg_object-obj_name = iv_obj_name.
  ls_stg_object-obj_type = iv_obj_type.
  ls_stg_object-zpackage = iv_package.
  PERFORM join_source_lines USING it_source CHANGING ls_stg_object-source.

  INSERT zdccrt_stg_obj FROM ls_stg_object.

  PERFORM parse_and_stage_dependencies USING iv_run_id iv_obj_name iv_dep_json.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  JOIN_SOURCE_LINES
*&---------------------------------------------------------------------*
*       IT_SOURCE is read today exactly as GET_SOURCE_FOR_LLD_OBJECT
*       returns it (unchanged) - this just joins it into one STRING with
*       embedded newlines for the SOURCE column, instead of GT_OUTPUT's
*       one-table-row-per-line shape.
*&---------------------------------------------------------------------*
FORM join_source_lines USING it_source TYPE tt_code_line
                        CHANGING cv_joined TYPE string.
  DATA lv_first TYPE abap_bool VALUE abap_true.

  CLEAR cv_joined.

  LOOP AT it_source INTO DATA(ls_line).
    IF lv_first = abap_true.
      cv_joined = ls_line-line.
      lv_first = abap_false.
    ELSE.
      cv_joined = |{ cv_joined }{ cl_abap_char_utilities=>newline }{ ls_line-line }|.
    ENDIF.
  ENDLOOP.
ENDFORM.

*&=======================================================================*
*& Minimal JSON walker (DB mode only)
*&
*& ZCR_GET_DEPENDENCY_OBJ_NEW/Z_GET_DDIC_INFO emit JSON strings, not
*& native ABAP structures - FILE mode has always just embedded that text
*& as-is, but ZLLD_STG_DEPENDENCY/_DDIC need DEPENDENCY_TYPE/NAME and
*& DDIC_TYPE/NAME split into their own columns (see the brief). Rather
*& than depend on an add-on-provided JSON library (e.g. /UI2/CL_JSON -
*& not guaranteed present on every system, and awkward for "re-serialize
*& this nested object as its own opaque string" which SIGNATURE_JSON/
*& DETAIL_JSON need), this is a small, self-contained bracket-matching
*& scanner written against the EXACT, already-confirmed real shapes (see
*& lld_step2/parser.py on the Python side, validated against real
*& ZZBA91 output):
*&   dependency JSON: [{"TYPE":owner_type,"NAME":owner_name,
*&                      "DEPENDENCIES":[{"TYPE":...,"NAME":...,
*&                                       "SIGNATURE":{...}?}, ...]}]
*&   DDIC JSON:        {"PACKAGES":[{"DOMAIN":[{"NAME":...,...}],
*&                      "DATA_ELEMENT":[...],"TABLE":[...],
*&                      "STRUCTURE":[...],"TABLE_TYPE":[...]}]}
*& VERIFY: this has not been run against a live system - the shapes
*& above are confirmed from real extraction output already processed by
*& this project's Python side, not from a live ABAP test of this scanner
*& itself. Test against a real, non-trivial dependency JSON (multiple
*& entries, at least one WITH a SIGNATURE and one WITHOUT) before
*& trusting DB mode's staged rows.
*&=======================================================================*

*&---------------------------------------------------------------------*
*&      Form  FIND_MATCHING_BRACKET
*&---------------------------------------------------------------------*
*       Given IV_JSON and IV_OPEN_POS pointing at a '{' or '[', returns
*       the offset of its matching closing bracket, correctly skipping
*       brackets that appear inside quoted string values (tracking
*       "in a string" state and backslash-escaping so an escaped quote
*       doesn't end the string early). Returns -1 if unmatched.
*&---------------------------------------------------------------------*
FORM find_matching_bracket USING iv_json     TYPE string
                                  iv_open_pos TYPE i
                            CHANGING cv_close_pos TYPE i.
  DATA: lv_len        TYPE i,
        lv_pos        TYPE i,
        lv_depth      TYPE i,
        lv_open_char  TYPE c LENGTH 1,
        lv_close_char TYPE c LENGTH 1,
        lv_char       TYPE c LENGTH 1,
        lv_in_string  TYPE abap_bool,
        lv_escaped    TYPE abap_bool.

  cv_close_pos = -1.
  lv_len = strlen( iv_json ).
  CHECK iv_open_pos >= 0 AND iv_open_pos < lv_len.

  lv_open_char = substring( val = iv_json off = iv_open_pos len = 1 ).
  CASE lv_open_char.
    WHEN '{'. lv_close_char = '}'.
    WHEN '['. lv_close_char = ']'.
    WHEN OTHERS. RETURN.
  ENDCASE.

  lv_depth     = 0.
  lv_in_string = abap_false.
  lv_escaped   = abap_false.

  DO lv_len - iv_open_pos TIMES.
    lv_pos  = iv_open_pos + sy-index - 1.
    lv_char = substring( val = iv_json off = lv_pos len = 1 ).

    IF lv_in_string = abap_true.
      IF lv_escaped = abap_true.
        lv_escaped = abap_false.
      ELSEIF lv_char = '\'.
        lv_escaped = abap_true.
      ELSEIF lv_char = '"'.
        lv_in_string = abap_false.
      ENDIF.
      CONTINUE.
    ENDIF.

    IF lv_char = '"'.
      lv_in_string = abap_true.
    ELSEIF lv_char = lv_open_char.
      lv_depth = lv_depth + 1.
    ELSEIF lv_char = lv_close_char.
      lv_depth = lv_depth - 1.
      IF lv_depth = 0.
        cv_close_pos = lv_pos.
        RETURN.
      ENDIF.
    ENDIF.
  ENDDO.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  STRIP_OUTER_JSON_ARRAY
*&---------------------------------------------------------------------*
*       Returns the substring strictly between a JSON string's first '['
*       and that bracket's matching ']', regardless of surrounding
*       whitespace - i.e. "[ {\"A\":1}, {\"A\":2} ]" -> " {\"A\":1},
*       {\"A\":2} " (untrimmed; SPLIT_JSON_TOP_LEVEL_ELEMENTS below
*       skips non-bracket characters on its own, so leading/trailing
*       whitespace here is harmless).
*&---------------------------------------------------------------------*
FORM strip_outer_json_array USING iv_json TYPE string
                             CHANGING cv_inner TYPE string.
  DATA: lv_open  TYPE i,
        lv_close TYPE i.

  CLEAR cv_inner.

  FIND FIRST OCCURRENCE OF '[' IN iv_json MATCH OFFSET lv_open.
  CHECK sy-subrc = 0.

  PERFORM find_matching_bracket USING iv_json lv_open CHANGING lv_close.
  CHECK lv_close > lv_open.

  cv_inner = substring( val = iv_json off = lv_open + 1 len = lv_close - lv_open - 1 ).
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  SPLIT_JSON_TOP_LEVEL_ELEMENTS
*&---------------------------------------------------------------------*
*       Splits an array's inner body (as returned by
*       STRIP_OUTER_JSON_ARRAY) into its top-level '{...}'/'[...]'
*       element substrings, skipping commas/whitespace between them.
*       Every element this report's two known JSON shapes ever contain
*       is itself an object, never a bare scalar.
*&---------------------------------------------------------------------*
FORM split_json_top_level_elements USING iv_array_body TYPE string
                                    CHANGING ct_elements TYPE string_table.
  DATA: lv_len   TYPE i,
        lv_pos   TYPE i,
        lv_close TYPE i,
        lv_char  TYPE c LENGTH 1.

  CLEAR ct_elements.
  lv_len = strlen( iv_array_body ).
  lv_pos = 0.

  WHILE lv_pos < lv_len.
    lv_char = substring( val = iv_array_body off = lv_pos len = 1 ).
    IF lv_char = '{' OR lv_char = '['.
      PERFORM find_matching_bracket USING iv_array_body lv_pos CHANGING lv_close.
      IF lv_close < lv_pos.
        EXIT.  " unmatched bracket - malformed input, stop rather than loop forever
      ENDIF.
      APPEND substring( val = iv_array_body off = lv_pos len = lv_close - lv_pos + 1 ) TO ct_elements.
      lv_pos = lv_close + 1.
    ELSE.
      lv_pos = lv_pos + 1.
    ENDIF.
  ENDWHILE.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  EXTRACT_JSON_STRING_FIELD
*&---------------------------------------------------------------------*
*       Extracts a simple string-valued field (e.g. "TYPE":"METH",
*       "NAME":"FOO") from one JSON object's raw text. Unescapes \" and
*       \\ only - real dependency/DDIC TYPE and NAME values are ABAP
*       identifiers and never contain other JSON escapes in practice.
*       VERIFY if a NAME value is ever found to legitimately need fuller
*       JSON unescaping (e.g. \uXXXX).
*
*       CV_VALUE is CHANGING ... TYPE CSEQUENCE (a generic ABAP type
*       covering STRING and any fixed CHAR length) deliberately, not a
*       fixed TYPE STRING: this FORM's three callers pass different
*       concrete types for it - ZDCCRT_STG_DEP-DEPENDENCY_TYPE/
*       DEPENDENCY_NAME are genuinely STRING, but STAGE_DDIC_SECTION's
*       ZDCCRT_STG_DDIC-DDIC_NAME is CHAR30 (STRING is rejected as a
*       table key component on this system - see
*       DDIC_TABLES_TO_CREATE_LLD.txt). A classic FORM's default
*       by-reference CHANGING binding requires the actual parameter's
*       type to be IDENTICAL to the formal's, so no single fixed type
*       (STRING or CHAR30) can match every caller - a VALUE(...) pass-
*       by-value-result copy would work for any ONE fixed type too, but
*       CSEQUENCE is the more correct fit here: it lets ABAP bind BY
*       REFERENCE directly to whichever concrete text type the caller
*       actually passes, with no copying at all.
*&---------------------------------------------------------------------*
FORM extract_json_string_field USING iv_json_obj TYPE string
                                      iv_field    TYPE string
                                CHANGING cv_value TYPE csequence.
  DATA: lv_regex TYPE string,
        lv_raw   TYPE string.

  CLEAR cv_value.

  " Built via && concatenation of classical single-quoted literals, not
  " a |...| string template - a template's \ /{ /} /| characters are all
  " escape-significant (need doubling to appear literally), which this
  " regex is full of; single-quoted literals have no such special
  " characters at all, so this is simpler and correct as written.
  lv_regex = '"' && iv_field && '"\s*:\s*"((?:[^"\\]|\\.)*)"'.

  FIND REGEX lv_regex IN iv_json_obj SUBMATCHES lv_raw.
  CHECK sy-subrc = 0.

  REPLACE ALL OCCURRENCES OF '\"' IN lv_raw WITH '"'.
  REPLACE ALL OCCURRENCES OF '\\' IN lv_raw WITH '\'.
  cv_value = lv_raw.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  EXTRACT_JSON_RAW_FIELD
*&---------------------------------------------------------------------*
*       Extracts a nested object/array-valued field (e.g. "SIGNATURE":
*       {...}, "DEPENDENCIES":[...], "PACKAGES":[...]) as its exact raw
*       JSON substring, unparsed - this is what lets SIGNATURE_JSON/
*       DETAIL_JSON stay opaque blobs per the brief, without needing a
*       full JSON-to-ABAP deserializer. Blank if the field is absent or
*       is not itself an object/array (the two real callers of this form
*       never expect a bare scalar here).
*&---------------------------------------------------------------------*
FORM extract_json_raw_field USING iv_json_obj TYPE string
                                   iv_field    TYPE string
                             CHANGING cv_raw   TYPE string.
  DATA: lv_regex     TYPE string,
        lv_key_end   TYPE i,
        lv_match_len TYPE i,
        lv_scan_pos  TYPE i,
        lv_close_pos TYPE i,
        lv_char      TYPE c LENGTH 1.

  CLEAR cv_raw.

  " Same reasoning as EXTRACT_JSON_STRING_FIELD's own LV_REGEX - built
  " via && concatenation of classical literals, not a |...| template.
  lv_regex = '"' && iv_field && '"\s*:\s*'.
  FIND REGEX lv_regex IN iv_json_obj MATCH OFFSET lv_key_end MATCH LENGTH lv_match_len.
  CHECK sy-subrc = 0.

  lv_scan_pos = lv_key_end + lv_match_len.
  CHECK lv_scan_pos < strlen( iv_json_obj ).
  lv_char = substring( val = iv_json_obj off = lv_scan_pos len = 1 ).

  CHECK lv_char = '{' OR lv_char = '['.

  PERFORM find_matching_bracket USING iv_json_obj lv_scan_pos CHANGING lv_close_pos.
  CHECK lv_close_pos >= lv_scan_pos.

  cv_raw = substring( val = iv_json_obj off = lv_scan_pos len = lv_close_pos - lv_scan_pos + 1 ).
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  PARSE_AND_STAGE_DEPENDENCIES
*&---------------------------------------------------------------------*
*       IV_DEP_JSON is exactly what BUILD_DEPENDENCY_FOR_OBJECT already
*       returned (unchanged) - this only walks it. Per
*       ZCR_GET_DEPENDENCY_OBJ_NEW's per-object contract (see
*       BUILD_DEPENDENCY_FOR_OBJECT's own comment), the outer array has
*       exactly one entry; only that first entry is read.
*&---------------------------------------------------------------------*
FORM parse_and_stage_dependencies USING iv_run_id   TYPE sysuuid_x16
                                         iv_obj_name TYPE e071-obj_name
                                         iv_dep_json TYPE string.
  DATA: lv_outer_body    TYPE string,
        lt_outer_entries TYPE string_table,
        lv_deps_raw      TYPE string,
        lt_dep_entries   TYPE string_table,
        lv_seq           TYPE i,
        ls_stg_dep       TYPE zdccrt_stg_dep.

  CHECK iv_dep_json IS NOT INITIAL.

  PERFORM strip_outer_json_array USING iv_dep_json CHANGING lv_outer_body.
  PERFORM split_json_top_level_elements USING lv_outer_body CHANGING lt_outer_entries.

  READ TABLE lt_outer_entries INTO DATA(lv_outer_entry) INDEX 1.
  CHECK sy-subrc = 0.

  PERFORM extract_json_raw_field USING lv_outer_entry 'DEPENDENCIES' CHANGING lv_deps_raw.
  CHECK lv_deps_raw IS NOT INITIAL.

  PERFORM strip_outer_json_array USING lv_deps_raw CHANGING lv_deps_raw.
  PERFORM split_json_top_level_elements USING lv_deps_raw CHANGING lt_dep_entries.

  lv_seq = 0.
  LOOP AT lt_dep_entries INTO DATA(lv_dep_entry).
    lv_seq = lv_seq + 1.

    CLEAR ls_stg_dep.
    ls_stg_dep-run_id         = iv_run_id.
    ls_stg_dep-obj_name       = iv_obj_name.
    ls_stg_dep-dependency_seq = lv_seq.

    PERFORM extract_json_string_field USING lv_dep_entry 'TYPE' CHANGING ls_stg_dep-dependency_type.
    PERFORM extract_json_string_field USING lv_dep_entry 'NAME' CHANGING ls_stg_dep-dependency_name.
    PERFORM extract_json_raw_field    USING lv_dep_entry 'SIGNATURE' CHANGING ls_stg_dep-signature_json.

    INSERT zdccrt_stg_dep FROM ls_stg_dep.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  STAGE_PACKAGE_DDIC
*&---------------------------------------------------------------------*
*       IV_DDIC_JSON is exactly what BUILD_PACKAGE_DDIC_JSON already
*       returned (unchanged) - this only walks it.
*&---------------------------------------------------------------------*
FORM stage_package_ddic USING iv_run_id    TYPE sysuuid_x16
                               iv_ddic_json TYPE string.
  DATA: lv_packages_body TYPE string,
        lt_pkg_entries   TYPE string_table.

  CHECK iv_ddic_json IS NOT INITIAL.

  PERFORM extract_json_raw_field USING iv_ddic_json 'PACKAGES' CHANGING lv_packages_body.
  CHECK lv_packages_body IS NOT INITIAL.

  PERFORM strip_outer_json_array USING lv_packages_body CHANGING lv_packages_body.
  PERFORM split_json_top_level_elements USING lv_packages_body CHANGING lt_pkg_entries.

  LOOP AT lt_pkg_entries INTO DATA(lv_pkg_entry).
    PERFORM stage_ddic_section USING iv_run_id lv_pkg_entry 'DOMAIN'       'DOMA'.
    PERFORM stage_ddic_section USING iv_run_id lv_pkg_entry 'DATA_ELEMENT' 'DTEL'.
    PERFORM stage_ddic_section USING iv_run_id lv_pkg_entry 'TABLE'        'TABL'.
    PERFORM stage_ddic_section USING iv_run_id lv_pkg_entry 'STRUCTURE'    'STRU'.
    PERFORM stage_ddic_section USING iv_run_id lv_pkg_entry 'TABLE_TYPE'   'TTYP'.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  STAGE_DDIC_SECTION
*&---------------------------------------------------------------------*
FORM stage_ddic_section USING iv_run_id    TYPE sysuuid_x16
                               iv_pkg_entry TYPE string
                               iv_section   TYPE string
                               iv_ddic_type TYPE char4.
  DATA: lv_section_body TYPE string,
        lt_entries      TYPE string_table,
        ls_stg_ddic     TYPE zdccrt_stg_ddic.

  PERFORM extract_json_raw_field USING iv_pkg_entry iv_section CHANGING lv_section_body.
  CHECK lv_section_body IS NOT INITIAL.

  PERFORM strip_outer_json_array USING lv_section_body CHANGING lv_section_body.
  PERFORM split_json_top_level_elements USING lv_section_body CHANGING lt_entries.

  LOOP AT lt_entries INTO DATA(lv_entry).
    CLEAR ls_stg_ddic.
    ls_stg_ddic-run_id    = iv_run_id.
    ls_stg_ddic-ddic_type = iv_ddic_type.
    PERFORM extract_json_string_field USING lv_entry 'NAME' CHANGING ls_stg_ddic-ddic_name.
    CHECK ls_stg_ddic-ddic_name IS NOT INITIAL.
    ls_stg_ddic-detail_json = lv_entry.

    " MODIFY, not INSERT: cheap insurance against the same DDIC object
    " appearing more than once (e.g. a future multi-package-scoped DDIC
    " blob) colliding on ZDCCRT_STG_DDIC's (RUN_ID, DDIC_TYPE, DDIC_NAME)
    " key - not expected from this report's own single-package
    " BUILD_PACKAGE_DDIC_JSON call, but harmless either way.
    MODIFY zdccrt_stg_ddic FROM ls_stg_ddic.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  READ_SYNC_LOG
*&---------------------------------------------------------------------*
FORM read_sync_log USING iv_package TYPE devclass
                    CHANGING es_log   TYPE zdccrt_sync_log
                             ev_found TYPE abap_bool.
  CLEAR: es_log, ev_found.

  SELECT SINGLE * FROM zdccrt_sync_log INTO @es_log WHERE zpackage = @iv_package.
  IF sy-subrc = 0.
    ev_found = abap_true.
  ENDIF.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  UPDATE_SYNC_LOG
*&---------------------------------------------------------------------*
FORM update_sync_log USING iv_package      TYPE devclass
                            iv_run_type     TYPE char4
                            iv_hwm          TYPE e070-trkorr
                            iv_object_count TYPE i
                            iv_status       TYPE char10.
  DATA: ls_log TYPE zdccrt_sync_log,
        lv_ts  TYPE timestampl.

  GET TIME STAMP FIELD lv_ts.

  ls_log-zpackage        = iv_package.
  ls_log-last_sync_ts    = lv_ts.
  ls_log-last_trkorr_hwm = iv_hwm.
  ls_log-run_type        = iv_run_type.
  ls_log-object_count    = iv_object_count.
  ls_log-status          = iv_status.

  MODIFY zdccrt_sync_log FROM ls_log.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  REFRESH_SYNC_OBJECTS
*&---------------------------------------------------------------------*
*       Full replace of this package's snapshot with its CURRENT live
*       inventory (GT_CURRENT_INVENTORY, built once at the top of MAIN)
*       - needed for the NEXT run's deletion detection regardless of
*       how narrow this run's own extraction scope was.
*&---------------------------------------------------------------------*
FORM refresh_sync_objects USING iv_package TYPE devclass
                                 it_current TYPE tt_lld_obj.
  DATA: lt_rows TYPE STANDARD TABLE OF zdccrt_sync_obj,
        lv_ts   TYPE timestampl.

  GET TIME STAMP FIELD lv_ts.

  DELETE FROM zdccrt_sync_obj WHERE zpackage = @iv_package.

  LOOP AT it_current INTO DATA(ls_current).
    APPEND VALUE #( zpackage     = iv_package
                     obj_type     = ls_current-obj_type
                     obj_name     = ls_current-obj_name
                     last_seen_ts = lv_ts ) TO lt_rows.
  ENDLOOP.

  IF lt_rows IS NOT INITIAL.
    INSERT zdccrt_sync_obj FROM TABLE lt_rows.
  ENDIF.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  DETERMINE_CURRENT_HWM
*&---------------------------------------------------------------------*
*       Baseline HWM recorded after a FULL run: the most recently
*       released transport system-wide as of now. Its own package is
*       irrelevant - it's used purely as a timestamp anchor (via
*       GATHER_QUALIFYING_TRANSPORTS' AS4DATE/AS4TIME lookup), so the
*       very next INCR run only considers transports released after
*       this full extraction was taken, regardless of which package
*       they touch.
*&---------------------------------------------------------------------*
FORM determine_current_hwm CHANGING cv_hwm TYPE e070-trkorr.
  " Explicit flat-table declaration - see the comment in
  " BUILD_PACKAGE_INVENTORY for why this matters for a single-column
  " SELECT (inline @DATA(...) would create a one-component structure
  " table instead, which READ TABLE ... INTO cv_hwm could not then move
  " into an elementary target).
  DATA lt_recent TYPE STANDARD TABLE OF e070-trkorr.

  SELECT trkorr FROM e070
    INTO TABLE @lt_recent
    WHERE trstatus = 'R'
    ORDER BY as4date DESCENDING, as4time DESCENDING.

  CLEAR cv_hwm.
  READ TABLE lt_recent INTO cv_hwm INDEX 1.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  FINALIZE_SYNC_STATE
*&---------------------------------------------------------------------*
FORM finalize_sync_state USING iv_package  TYPE devclass
                                iv_run_type TYPE char4
                                iv_new_hwm  TYPE e070-trkorr.
  DATA lv_hwm TYPE e070-trkorr.

  IF iv_run_type = 'FULL'.
    PERFORM determine_current_hwm CHANGING lv_hwm.
  ELSE.
    IF iv_new_hwm IS NOT INITIAL.
      lv_hwm = iv_new_hwm.
    ELSE.
      " nothing qualified this run - HWM stays where it was
      lv_hwm = gs_sync_log-last_trkorr_hwm.
    ENDIF.
  ENDIF.

  PERFORM update_sync_log USING iv_package iv_run_type lv_hwm gv_extracted_count 'SUCCESS'.
  PERFORM refresh_sync_objects USING iv_package gt_current_inventory.
ENDFORM.

*&---------------------------------------------------------------------*
*& Screen 9000 PBO/PAI
*&---------------------------------------------------------------------*
*       Flow logic needed on screen 9000:
*         PBO: MODULE status_9000.
*         PAI: MODULE user_command_9000.
*       Extraction itself happens back in MAIN, after CALL SCREEN 9000
*       returns (matching the post-screen CHECK gv_multi_cancelled
*       pattern ZCR_AURA_CODE_EXTRACTOR's own multi-flows already use) -
*       EXEC here only closes the screen, it does not extract anything.
*&---------------------------------------------------------------------*
MODULE status_9000 OUTPUT.
  SET PF-STATUS 'STATUS_9000'.

  IF go_container IS NOT BOUND.
    PERFORM create_lld_alv.
  ENDIF.
ENDMODULE.

MODULE user_command_9000 INPUT.
  DATA lv_ok_code TYPE sy-ucomm.

  lv_ok_code = sy-ucomm.
  CLEAR sy-ucomm.

  CASE lv_ok_code.
    WHEN 'EXEC'.
      IF go_alv_grid IS BOUND.
        go_alv_grid->check_changed_data( ).
      ENDIF.
      LEAVE TO SCREEN 0.

    WHEN 'BACK' OR 'EXIT' OR 'CANC'.
      gv_multi_cancelled = abap_true.
      LEAVE TO SCREEN 0.

    WHEN 'SELALL'.
      LOOP AT gt_lld_multi_obj ASSIGNING FIELD-SYMBOL(<fs_sel>).
        <fs_sel>-checked = abap_true.
      ENDLOOP.
      PERFORM refresh_lld_alv_display.

    WHEN 'DESELALL'.
      LOOP AT gt_lld_multi_obj ASSIGNING FIELD-SYMBOL(<fs_desel>).
        <fs_desel>-checked = abap_false.
      ENDLOOP.
      PERFORM refresh_lld_alv_display.
  ENDCASE.
ENDMODULE.
