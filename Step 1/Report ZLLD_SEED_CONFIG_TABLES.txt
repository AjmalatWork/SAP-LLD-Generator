REPORT zlld_seed_config_tables.

*&---------------------------------------------------------------------*
*& ZLLD_SEED_CONFIG_TABLES
*&---------------------------------------------------------------------*
*  One-time (idempotent - safe to re-run) seeding of ZLLD_EDGE_KIND_MAP
*  and ZLLD_CONFIG for ZLLD_EXTRACT_TO_DB, per
*  step2_native_processing_brief.md ("seed it with the exact mapping
*  already validated against real ZZBA91 data" / "seed with at minimum:
*  the stopword list... and a placeholder for chunk-merge minimum
*  length"). Run this ONCE after creating both tables in SE11, before
*  the first ZLLD_EXTRACT_TO_DB call. Uses MODIFY throughout, so
*  re-running it later (e.g. after adding a newly-observed
*  DEPENDENCY_TYPE by editing the VALUE #( ... ) list below and
*  re-running) is always safe.
*
*  Deliberately a table, not a hardcoded CASE - see ZLLD_EXTRACT_TO_DB's
*  ZLLD_LOOKUP_EDGE_KIND form. Adding a row here for a newly-observed
*  DEPENDENCY_TYPE never needs a transport for logic, only a data change
*  (SM30 on ZLLD_EDGE_KIND_MAP directly also works going forward - this
*  report is just the bulk one-time load).
*
*  EDGE_KIND/IS_CALL_LIKE values below are a straight port of
*  EDGE_KIND_MAP/CALL_LIKE_EDGE_KINDS from graph_loader.py, mapped onto
*  the real DEPENDENCY_TYPE vocabulary confirmed on ZZBA91 (18 types -
*  see the real-data validation report / this project's acceptance
*  criteria for ZLLD_EXTRACT_TO_DB). CALL_LIKE = METH/OM (calls_method)
*  and FUNC (calls_function) only, matching Python's tuple - everything
*  else is a structural/reference edge, not a call.
*&---------------------------------------------------------------------*

START-OF-SELECTION.
  PERFORM seed_edge_kind_map.
  PERFORM seed_config.
  WRITE: / 'ZLLD_EDGE_KIND_MAP and ZLLD_CONFIG seeded (or re-seeded, unchanged if already current).'.

*&---------------------------------------------------------------------*
*&      Form  SEED_EDGE_KIND_MAP
*&---------------------------------------------------------------------*
FORM seed_edge_kind_map.
  TYPES: tt_edge_seed TYPE STANDARD TABLE OF zlld_edge_kind_map WITH EMPTY KEY.

  DATA(lt_seed) = VALUE tt_edge_seed(
    ( dependency_type = 'METH' edge_kind = 'calls_method'        is_call_like = abap_true  )
    ( dependency_type = 'OM'   edge_kind = 'calls_method'        is_call_like = abap_true  )
    ( dependency_type = 'FUNC' edge_kind = 'calls_function'      is_call_like = abap_true  )
    ( dependency_type = 'CLAS' edge_kind = 'class_ref'           is_call_like = abap_false )
    ( dependency_type = 'STRU' edge_kind = 'structure_ref'       is_call_like = abap_false )
    ( dependency_type = 'MESS' edge_kind = 'message_ref'         is_call_like = abap_false )
    ( dependency_type = 'OA'   edge_kind = 'reference'           is_call_like = abap_false )
    ( dependency_type = 'DTEL' edge_kind = 'data_element_ref'    is_call_like = abap_false )
    ( dependency_type = 'INCL' edge_kind = 'includes'            is_call_like = abap_false )
    ( dependency_type = 'INTF' edge_kind = 'implements'          is_call_like = abap_false )
    ( dependency_type = 'DGT'  edge_kind = 'generic_type_ref'    is_call_like = abap_false )
    ( dependency_type = 'FUGR' edge_kind = 'function_group_ref'  is_call_like = abap_false )
    ( dependency_type = 'PROG' edge_kind = 'program_ref'         is_call_like = abap_false )
    ( dependency_type = 'TABL' edge_kind = 'table_ref'           is_call_like = abap_false )
    ( dependency_type = 'MSAG' edge_kind = 'message_class_ref'   is_call_like = abap_false )
    ( dependency_type = 'TTYP' edge_kind = 'table_type_ref'      is_call_like = abap_false )
    ( dependency_type = 'TYPE' edge_kind = 'type_ref'            is_call_like = abap_false )
    ( dependency_type = 'TRAN' edge_kind = 'transaction_ref'     is_call_like = abap_false )
  ).

  LOOP AT lt_seed INTO DATA(ls_seed).
    MODIFY zlld_edge_kind_map FROM ls_seed.
  ENDLOOP.
ENDFORM.

*&---------------------------------------------------------------------*
*&      Form  SEED_CONFIG
*&---------------------------------------------------------------------*
*       Short, tunable-without-a-transport stopword list of ABAP-generic
*       noise tokens that would otherwise dominate every chunk
*       indiscriminately - kept deliberately short per the brief. Add/
*       remove words directly in SM30 on ZLLD_CONFIG afterward; this
*       report only sets the initial baseline. CHUNK_MERGE_MIN_LINES is
*       a placeholder default (3) - the brief flags it as a knob to
*       tune, not a calibrated value from real-data evidence yet.
*
*       Deliberately NOT seeded here (per the brief): scoring weights,
*       tier multipliers, or the seed-eligibility floor - those need
*       their own recalibration exercise against real lexical score
*       distributions, which don't exist yet, and belong to the future
*       retrieval report's own brief.
*&---------------------------------------------------------------------*
FORM seed_config.
  TYPES: tt_config_seed TYPE STANDARD TABLE OF zlld_config WITH EMPTY KEY.

  DATA(lt_seed) = VALUE tt_config_seed(
    ( config_key = 'STOPWORDS'
      config_value = 'data,type,types,begin,end,if,endif,else,elseif,endcase,case,when,'
                   && 'value,values,class,endclass,method,endmethod,form,endform,perform,'
                   && 'function,endfunction,loop,endloop,into,from,where,select,table,'
                   && 'standard,structure,changing,using,importing,exporting,returning,'
                   && 'optional,is,not,and,or,check,clear,move,append,read,write' )
    ( config_key = 'CHUNK_MERGE_MIN_LINES' config_value = '3' )
  ).

  LOOP AT lt_seed INTO DATA(ls_seed).
    MODIFY zlld_config FROM ls_seed.
  ENDLOOP.
ENDFORM.
